Segmented autotune search compression

1704/1704 cases complete. All paths use the same unchanged attention kernel and static selector on AMD R9700/gfx1201.

Fresh full and compressed startup searches use matched inputs at the real warmup ceiling. Paired runtime measurements use independent inputs and the production cache lookup, including smaller actual shapes. Warm timing uses repeated graph calls; cold timing evicts 256 MiB outside graph-internal GPU events. Compiler caches were prewarmed. These are equal-case-weight kernel speedups, not model throughput.

The compressed search screens native4 on each geometry, retains the default, and expands normal/native1 on the top eight geometries plus the default. Failed native4 anchors retain their other conversions. Each stage measures its own default baseline. Existing correctness and warm/cold promotion checks are preserved.
